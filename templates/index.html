College Lab Experiment 3 Manual & Specifications

1. Experiment Aim

To design, develop, and evaluate an intelligent, offline-capable customer support email assistant leveraging open-weight LLMs (Ollama llama3.2) and dense sentence embeddings (Sentence Transformers) for semantic historical precedent retrieval.

2. Architecture Flow

  1. Input Capture: Parse Customer Name, Email, Subject, and Body using Pandas/Flask.
  2. Intent Recognition: Zero-shot classification into business intent categories.
  3. Dense Retrieval: Compute 384-dimensional dense vectors with all-MiniLM-L6-v2; rank historical tickets by Cosine Similarity.
  4. Contextual Generation: Feed retrieved similar historical resolution into llama3.2 prompt template.
  5. Controllable Tone Rewrite: Zero-shot rewrite engine across Formal, Friendly, Empathetic, Concise, and Urgent styles.
  6. Local Persistence: Atomic append to data/saved_replies.json.

3. Execution Commands

ollama pull llama3.2
pip install -r requirements.txt
python app.py
